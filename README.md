# TP2 — Portada de diario con FlexBox

Actividad de diseño web: portada de un diario ficticio usando Flexbox y Mobile First.

🔗 https://matil11.github.io/Tp2/

## Archivos CSS

- `normalize.css` — reset cross-browser
- `base.css` — variables y tipografía
- `layout.css` — estructura y media queries
- `components.css` — estilos de cada componente

## Breakpoints

- Mobile (base): 1 columna, menú hamburguesa
- Tablet 600px: grids de 2 columnas
- Desktop 900px: sidebar + nav horizontal
- Desktop 1100px+: 3 columnas en grids
